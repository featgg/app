# Mockups

The authority of these files is defined in `../spec.md` (Status block); this
note repeats it here so nobody opens one without that context.

- `layout-editor.html` — normative for editor interaction only (spec §9.1):
  its mutations and drop-zone semantics.
- `profile-view.html` — a non-normative visual reference, kept for the
  per-archetype motif vocabulary and the background/theme treatment. It renders
  the pre-v4 card anatomy and is not a contract.
